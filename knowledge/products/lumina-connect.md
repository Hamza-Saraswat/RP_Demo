# Lumina Connect

Lumina Connect supplies governed, analytics-ready Realpage data, with business context already included, to the cloud platforms, BI tools, and AI agents that multifamily teams use. It has two paths, Lumina Data Cloud and Lumina Model Connect, which can be used separately or together.

## What it does

- Gives zero-copy access to curated Realpage data through Snowflake, Databricks, Microsoft Fabric, Google Cloud Platform, and BI tools like Power BI (Lumina Data Cloud)
- Lets customers' AI agents query governed Realpage data via an MCP connector, using curated models built for agent reasoning (Lumina Model Connect)
- Supplies cleansed, normalized, deduplicated data with consistent definitions and predefined metrics, so teams do not have to rebuild meaning from raw records
- Removes the need for customers to build and maintain their own ingestion pipelines
- Allows Realpage data to be blended with enterprise and third-party data for custom dashboards, KPIs, and analysis

## Who uses it

Multifamily organizations' data, analytics, and BI teams, along with those running their own AI agents, who want ready-to-use Realpage data.
