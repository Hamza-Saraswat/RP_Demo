# Budgeting

Budgeting is a software product for property management companies that replaces spreadsheets for building budgets, reforecasting, consolidation and reporting. It connects with property management and accounting systems so data does not have to be re-entered by hand.

## What it does

- Imports data from connected property management and accounting software so users skip manual entry and template setup
- Updates changes to the budgeting model everywhere automatically, avoiding the formula and link mistakes common in spreadsheets
- Sets up a reforecasting model quickly and loads actual results, with the option to base figures on the original budget, prior-period actuals or earlier reforecasts
- Provides real-time detailed or summary reports, including 12-period and long-term rolling forecasts and variance-to-budget views
- Keeps budgets in one central, secure location that stakeholders can view and collaborate on at any time

## Who uses it

Property management companies and their finance and accounting teams that prepare property budgets and reforecasts.
